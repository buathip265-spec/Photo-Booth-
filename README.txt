ใหม่ใน v6:

  วิดีโอ 1280×960 บิตเรต 10 Mbps ประมวลผลด้วย GPU (WebGL) ใช้ได้บน Safari/iPad (ถ้าเครื่องช้าเกินจะใช้โหมด 960×720 แทนอัตโนมัติ)
- หมายเหตุ: ความคมชัดเห็นผลในไฟล์ที่ได้ ไม่ใช่ในจอพรีวิวกล้อง

  + ช่อง "เลือกกล้อง / เลนส์" (โผล่เมื่อเครื่องมีกล้องมากกว่า 1 ตัว) เลือกเลนส์ปกติแทนเลนส์มุมกว้างได้

  วิดีโอบันทึกตลอดช่วงนับถอยหลังและถ่าย (มีตัวเลขนับถอยหลัง แฟลช และชื่อแบรนด์) — Chrome/Edge/Safari ใหม่ได้ .mp4, บางเบราว์เซอร์ได้ .webm
  ติ๊กปิด "บันทึกวิดีโอระหว่างถ่าย" ได้ถ้าไม่ต้องการ

(ของเดิมจาก v3: รวม v2 ที่แก้บั๊ก + Admin Login + Frame Manager)

วิธีเปิดใช้งาน:
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ใน VS Code แล้วใช้ Live Server หรือรัน python -m http.server 8000
3) เปิด http://localhost:8000
4) กด Camera Studio > เปิดกล้อง และอนุญาต Camera access

Admin:
- เข้าเมนู Admin จะเจอหน้า Login ก่อน  บัญชีทดลอง: admin / memo1234
- ล็อกอินค้างไว้จนปิดแท็บ (sessionStorage) กด "ออกจากระบบ" ได้ที่หัวหน้า Admin
- Frame Manager: ใส่ชื่อ เลือกแบบซ้อนทับ แล้วอัปโหลดไฟล์ (แนะนำ PNG พื้นหลังโปร่งใส)
  • ซ้อนบนแต่ละภาพ: ไฟล์สัดส่วน 4:3 เช่น 1200×900
  • ซ้อนทั้งแถบรูป: 1200×2924 (3 ภาพ), 1200×3756 (4 ภาพ), 1520×2047 (6 ภาพ)
  ระบบเดาแบบให้อัตโนมัติจากสัดส่วนไฟล์ และย่อไฟล์ที่ใหญ่เกิน 4000 px
- กรอบที่อัปโหลดเลือกใช้ได้ใน Camera Studio > "กรอบภาพเพิ่มเติม" และติดไปในไฟล์ที่ดาวน์โหลดด้วย
- กรอบเก็บใน IndexedDB ของเบราว์เซอร์ (จุได้มากกว่า localStorage) กรอบที่เคยเพิ่มจากเวอร์ชันเก่าจะถูกย้ายมาให้อัตโนมัติ

ฟีเจอร์จาก v2: กรอบ/โทนสีตามธีม 4 แบบ, สติกเกอร์ลากวางได้, 3/4/6 ภาพ (6 ภาพ = 2 คอลัมน์), วันที่บนแถบรูป, แฟลช, ปุ่มแชร์บนมือถือ, สถิติไม่หายเมื่อรีเฟรช

ข้อควรรู้:
- Login เป็นแค่ demo ฝั่งเบราว์เซอร์ ใครเปิดดูโค้ดก็เห็นรหัสผ่าน ห้ามใช้เป็นระบบจริงบนเว็บสาธารณะ
- กรอบ สถิติ และการตั้งค่าเก็บในเครื่อง/เบราว์เซอร์นั้นเท่านั้น ไม่แชร์ข้ามอุปกรณ์
- ใช้งานจริงต้องมี backend: ระบบล็อกอินฝั่งเซิร์ฟเวอร์ ฐานข้อมูล และที่เก็บไฟล์บนคลาวด์ (เช่น Firebase Auth + Firestore + Storage)
