MEMO PHOTO BOOTH — v2

วิธีเปิดใช้งาน:
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ใน VS Code แล้วใช้ Live Server หรือรัน python -m http.server 8000
3) เปิด http://localhost:8000
4) กด Camera Studio > เปิดกล้อง และอนุญาต Camera access

สิ่งที่แก้ใน v2:
- แก้ปุ่มเมนู/“เริ่มถ่ายรูป” ที่กดแล้วไม่เข้าหน้า Camera Studio / Admin
- thumbnail แสดงตามจำนวนภาพจริง (3 / 4 / 6)
- สถิติจำนวนภาพไม่รีเซ็ตเมื่อรีเฟรช, ชื่อแบรนด์และธีมถูกบันทึกในเครื่อง
- ระหว่างถ่ายจะล็อกปุ่ม ไม่ให้กดซ้ำ/ปิดกล้องกลางคัน
- การดาวน์โหลดไม่ค้าง (เดิมอาจค้างเพราะโหลดรูปไม่ทัน)

ฟีเจอร์ใหม่:
- กรอบตามธีม: Sweet Pink (ชมพู + ดอกไม้), Vintage Film (แถบฟิล์มมีรูหนาม), Y2K Pop (ไล่สีฟ้า-ม่วง), Mono Chic (กรอบดำ)
- โทนสีภาพตามธีม (ซีเปีย / ขาวดำ / สีจัด / ชมพูอุ่น) ทั้งตอนพรีวิวกล้องและในไฟล์จริง
- สติกเกอร์ 12 แบบ: แตะเพื่อวาง ลากเพื่อย้าย ปรับขนาด/ลบได้
- 6 ภาพจัดเป็น 2 คอลัมน์ x 3 แถว
- ใส่วันที่บนแถบรูป (เปิด/ปิดได้), ชื่อแบรนด์จาก Admin ขึ้นบนหัวแถบรูป
- เอฟเฟกต์แฟลช + ตัวบอกช็อตที่กำลังถ่าย
- ปุ่ม “แชร์” (มือถือที่รองรับ Web Share)
- Admin นับจำนวน Photo Strip ที่ดาวน์โหลด

หมายเหตุ:
- กล้องจริงใช้ getUserMedia จึงต้องเปิดผ่าน HTTPS หรือ localhost
- Admin ยังเป็น local demo (localStorage) ยังไม่มี backend / login / cloud database
- ภาพถ่ายอยู่ในหน่วยความจำของหน้าเว็บ ไม่ถูกอัปโหลดไปเซิร์ฟเวอร์
